# Selamat Datang: Catatan Belajar Pertamaku

Selamat datang di blogku! Ini adalah postingan contoh yang mendemonstrasikan **pipeline rendering MDX** dengan kotak catatan (callout) dan penyorotan sintaks.

## Mengapa MDX?

MDX memungkinkanku menyisipkan komponen Svelte interaktif langsung dalam catatanku. Berikut contoh blok kode:

```typescript
function sapa(nama: string): string {
  return `Halo, ${nama}!`;
}

console.log(sapa("Dunia"));
```
